# Roger Bos Engineering Portfolio

A free Vite + React portfolio website ready for GitHub and Vercel.

## How to use

1. Download and unzip this folder.
2. Upload the contents to a new GitHub repository.
3. Go to Vercel and import the GitHub repo.
4. Use these settings:
   - Framework Preset: Vite
   - Build Command: npm run build
   - Output Directory: dist
5. Deploy.

## Edit content

Main website content is in:

```text
src/main.jsx
```

Styling is in:

```text
src/styles.css
```
